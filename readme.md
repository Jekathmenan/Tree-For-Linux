# tree-clone

A custom implementation of the Linux `tree` command.

Lists all files and subdirectories of a given directory in a tree-like format. If no directory is specified as an argument, it defaults to the current working directory.

## Example Output

```text
.
   src/
      main.c
   install/
      tree
   README.md
```
